# app

The Next.js App Router: one folder per page or section, plus the API.

| Path | Holds |
| --- | --- |
| `layout.tsx`, `page.tsx` | The root layout (fallback metadata, fonts, structured data) and the home page. |
| `<section>/` | One folder per page or section, for example `certification`, `standard`, `registry`, `verify`, `aware`, `news`, `regulatory-map`. A section's `layout.tsx` usually sets its metadata with `pageMetadata()` from `lib/seo.ts`. |
| `api/` | Route handlers: `contact`, `subscribers`, `alpha`, `assessment`, `aware`, `aware-badge`, `registry`, `standard`, `notion`, `health`. Each validates its input and is rate limited. |
| `components/` | Site-wide components (navigation, footer, cookie consent, map, motion). `components/ui` holds the base UI primitives; `components/product` the platform tour. |
| `data/` | Typed reference content: capabilities, frameworks, glossary, guides, integrations, divisions. `country-frames.ts` and `country-detail.ts` are generated by `scripts/build-country-detail.mjs`: do not edit them by hand. |
| `hooks/` | Client-side React hooks. |
| `og/` | Draws social share images (`ogImageUrl()` in `lib/seo.ts`). |
| `robots.ts`, `sitemap.ts`, `llms.txt`, `security.txt` | For crawlers and security researchers. |

How it fits together: [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md).
