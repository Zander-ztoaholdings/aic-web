# Architecture

## The pieces

```
Browser ──> Coolify proxy (TLS) ──> aic-web (Next.js, built by Nixpacks, port 3000)
                                       │
          PostgreSQL (shared with aic-platform) <──┤  register, certificates, Aware badges, leads, contact
          Notion (AIC-CMS integration)  <──────────┤  articles, policy updates
          aic-platform  <──────────────────────────┤  AIC Aware badges (lib/aware-platform.ts)
          Resend  <────────────────────────────────┘  contact notifications
```

The traffic also runs the other way: the platform reads the published standard and the Aware question bank from this site (`/api/standard`, `/api/aware/instrument`), so there is one source for each.

## What the site does

| Area | Pages | Where the logic is |
| --- | --- | --- |
| Explaining AIC | `/`, `/certification`, `/about`, `/impartiality`, `/solutions`, `/insurers`, `/partners`, `/platform`, `/integrations` | Content in the pages and `app/data/` |
| The standard | `/standard`, `/frameworks` | `lib/standard-scoring.ts`, `app/api/standard` |
| Public register and verification | `/registry`, `/verify/[certId]` | `lib/registry.ts`, `lib/registry-notice.ts` |
| AIC Aware | `/aware`, `/registry/aware` | `lib/aware-*.ts`, `app/api/aware`, `app/api/assessment` |
| News and guides | `/news`, `/articles`, `/governance-hub`, `/guides`, `/glossary` | `lib/news.ts`, `lib/notion.ts` |
| Regulatory map | `/regulatory-map`, `/ai-governance-index` | `app/data/country-*.ts`, generated by `scripts/` from `data/` |
| Calls to action and forms | `/intake` (the offer), `/contact`, `/workshops` | `app/api/contact`, `lib/contact.ts`, `lib/validation.ts`, `lib/rate-limit.ts` |
| Legal | `/privacy`, `/terms`, `/paia`, `/disclosures`, `/security`, `/policy` | Static pages |

## Folders

See [app/README.md](../app/README.md) and [lib/README.md](../lib/README.md) for what is in each. In short: pages and API routes in `app/`, shared logic in `lib/`, static content and reference data in `app/data/`, tests in `__tests__/`.

## Things that are deliberate

- **Every page describes itself** through `lib/seo.ts` (`pageMetadata()`); the root layout is only the fallback. Social cards are drawn by `app/og`.
- **Analytics waits for consent** unless `NEXT_PUBLIC_ANALYTICS_DEFAULT_ON=true` (`lib/analytics-mode.ts`).
- **IP addresses are never stored raw**: forms hash them with `CONTACT_IP_SALT`.
- **Staging is never indexed** (`middleware.ts`, `AIC_ENV=staging`).
- **Structured data is plain `<script>`** in the server HTML, so crawlers read it without JavaScript.
- **Fonts** load from Google Fonts with a `<link>` in `app/layout.tsx`. Self-hosting them, as the platform now does, is a recommended follow-up: see the comment there.
